# Shoe placeholder icon

`app/src/main/res/drawable/ic_shoe_placeholder.xml` adapts the `shoe-sneaker` vector
from [Pictogrammers Material Design Icons](https://github.com/Templarian/MaterialDesign/blob/master/svg/shoe-sneaker.svg).
Icons are distributed under Apache-2.0; see `Apache-2.0.txt` and the
[upstream license](https://github.com/Templarian/MaterialDesign/blob/master/LICENSE).

## Plus Jakarta Sans

`app/src/main/res/font/plus_jakarta_sans.ttf` is the same variable font bundled by
iOS, licensed under SIL Open Font License1.1. The original notice and license are
packaged in `app/src/main/assets/PlusJakartaSans-OFL.txt`.
