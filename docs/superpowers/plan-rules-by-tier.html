2 · Phases

How a plan's weeks are split

Code sets phases, never the model. Race week and a recovery week close every plan. Plans of 12+ weeks taper in two steps (about 70% then 50% of peak); shorter plans in one step. A deload week (at most 80% of the week before) falls on every 4th week, never the last build week.

BaseBuildPeakTaper Zone 3 week (ultra, mountain day) deload (faded)

The Zone 3 window is the 8 weeks up to the peak week, deloads skipped. In the 13-week strip the window starts in week 2, so weeks 2–4 move from Base to Build pending.

6 · Gaps

Where the code and the doctrine still differ

  • Sore legs after long runs. The doctrine drops ME when long runs already leave the legs sore for 2–3 days. Code uses weekly climbing from the watch instead; a yes/no question in the block review would be the better signal.
